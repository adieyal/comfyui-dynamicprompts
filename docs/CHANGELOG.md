Unreleased - Added: `save_to_metadata` on the generator nodes writes the generated prompt into saved images' metadata. Fixed: Magic Prompt errors (such as transformers missing) now fail the run instead of producing an empty prompt; an empty Random Prompts template no longer crashes; YAML wildcard support (PyYAML) is now installed; example workflows match the current nodes, and the I'm Feeling Lucky example is removed. OutputString is deprecated: use ComfyUI's Preview Any to see a prompt.
0.3.0 - Fixes and some breaking changes. Fixed: seeds and caching (the same text, seed and wildcard files now give the same prompt, and `autorefresh` gives a new prompt every run), wildcard folder lookup and reloading (edits are picked up without a restart, extra folders can be set in `extra_model_paths.yaml`), Magic Prompt now loads its model on first use so startup is fast, Jinja2 templates can use wildcards, and OutputString. Upgraded dynamicprompts to 0.33, which fixes LoRA names containing `__`, hashtags in prompts, immediate variables and weights in YAML wildcard files. **Breaking:** I'm Feeling Lucky is removed (the lexica.art API is down); the Combinatorial seed is now the index of the combination to output; seed 0 is now a real seed. The install script and web extension are gone. `transformers` is no longer installed for Magic Prompt, so an existing (newer) version isn't downgraded.
0.2.1 - Fixed a bug due to a backwards incompatible change in the latest version of dynamicprompts that returns a SampleResult instead of a str
0.2.0 - Nodes now have settable seeds for reproducibility. Thanks to [@romeobuilderotti](https://github.com/romeobuilderotti/) for the inspiration for the inspiration. Also upgraded dynamicprompts to v0.30.1
0.1.3 - Wildcards in the ComfUI root are also supported for backwards compatibility
